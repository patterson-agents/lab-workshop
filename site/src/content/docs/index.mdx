## What this session covers

Five modules, one ladder: from context that is always loaded to capability that lives
outside the agent entirely. **AGENTS.md · Commands · Skills · Plugins · MCP servers.**
Eighteen hands-on lessons walk the same ladder that the projected deck and the
attendee workbook cover, so every attendee has a page to work from and a page to keep.
